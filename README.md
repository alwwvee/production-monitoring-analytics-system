# ПРОЕКТИРОВАНИЕ АНАЛИТИЧЕСКОЙ СИСТЕМЫ МОНИТОРИНГА ПРОИЗВОДСТВЕННОГО ПРОЦЕССА

## О проекте

Заказчик обратился с проблемой недостаточной прозрачности производственного процесса: простои оборудования, очереди на отдельных участках и задержки выполнения заказов не всегда удавалось своевременно выявлять, а часть производственных данных поступала с задержкой.

В ходе обсуждения текущего процесса были определены основные проблемы и потребности заказчика. На их основе сформированы задачи по анализу производственного процесса, определению ключевых показателей и проектированию аналитического решения для мониторинга производства.

**Роль:** Системный и бизнес-аналитик

## Задача

Необходимо было:

- проанализировать текущий производственный процесс;
- определить основные проблемы и проблемные участки;
- смоделировать текущее и целевое состояние процесса;
- определить показатели, необходимые для мониторинга производства;
- сформировать концепцию аналитического решения;
- формализовать требования для дальнейшей передачи в разработку.

## Что сделано

### 1. Контекст системы (C4 Model)

Определён контекст проектируемой аналитической системы: основные участники, внешние системы и взаимодействия с системой мониторинга производственного процесса.

### 2. Анализ текущего и целевого состояния процесса (AS-IS / TO-BE)

Проанализировано текущее состояние производственного процесса и определено целевое состояние с учётом предлагаемого аналитического решения.

Модели позволили зафиксировать существующий процесс и представить его целевую организацию.

### 3. Выявленные проблемы процесса / Точки боли

Выявлены основные проблемы производственного процесса и для каждой определены:

- причина возникновения;
- влияние на процесс;
- заинтересованные стороны.

В рамках анализа рассмотрены:

- простои оборудования;
- перегрузка отдельных участков;
- задержка поступления производственных данных;
- отсутствие чётких правил приоритизации заказов;
- простои оборудования при отсутствии ручной работы;
- выявление брака на поздних этапах процесса.

### 4. Моделирование бизнес-процесса (BPMN AS-IS / TO-BE)

Разработаны BPMN-модели текущего (**AS-IS**) и целевого (**TO-BE**) состояния производственного процесса.

### 5. Аналитическое решение

На основе выявленных проблем сформировано предлагаемое аналитическое решение для мониторинга производственного процесса.

Определены основные направления аналитики:

- **мониторинг узких мест производства** - загрузка оборудования, простои, очереди и причины задержек;
- **контроль выполнения заказов** - плановые и фактические показатели, а также риск нарушения сроков;
- **мониторинг производственного потока** - накопление очередей и перегрузка отдельных участков;
- **анализ простоев оборудования** - выявление повторяющихся причин потерь времени.

Для мониторинга определены ключевые показатели:

- загрузка узких мест;
- время простоя;
- очередь деталей перед узким местом;
- риск просрочки заказов;
- выполнение заказов в срок;
- объём незавершённого производства.

Предлагаемое решение направлено на то, чтобы сделать проблемные участки производственного процесса измеримыми и обеспечить руководство данными для своевременного выявления отклонений и принятия управленческих решений.

### 6. ОТ ТРЕБОВАНИЙ К РАЗРАБОТКЕ (процесс анализа и формализации требований)

Проработан процесс перехода от бизнес-потребности к требованиям, готовым к передаче в разработку:

**Анализ и сбор требований, формализация, передача в разработку**

Для каждого этапа определены:

- цель;
- входные данные;
- вопросы для уточнения;
- результат;
- критерии готовности.

При формализации требований рассмотрены правила расчёта показателей, источники данных, периодичность обновления и возможные ограничения реализации.

### 7. Риски неполной проработки требований

Определены риски, которые могут возникнуть при недостаточной детализации требований до начала разработки:

- разработка функциональности, не соответствующей ожиданиям пользователей;
- переработка дашбордов и требований;
- увеличение количества согласований;
- изменение требований после начала реализации;
- увеличение сроков реализации.

Для снижения рисков определены необходимые действия: дополнительное уточнение требований, фиксация недостающих параметров, актуализация постановки задачи и согласование требований с командой разработки.

### 8. Ограничения и допущения анализа

При проведении анализа зафиксированы ограничения и вопросы, требующие дополнительного уточнения:

- анализ выполнен на основе доступного описания производственного процесса и предоставленной информации о текущем состоянии;
- предполагается, что необходимые производственные данные могут быть получены из существующих систем учёта;
- для анализа простоев необходимо наличие информации о причинах остановок оборудования;
- перечень показателей и правила их расчёта требуют дополнительного согласования с заинтересованными сторонами.

## Результат

В результате для обозначенной заказчиком проблемы сформировано аналитическое решение, связывающее **проблемы производственного процесса, необходимые показатели, инструменты мониторинга, требования к дальнейшей реализации**.

Подготовлены аналитические артефакты, позволяющие перейти от общего описания проблемы к формализованному решению:

- контекст системы в нотации **C4 Model**;
- модели **AS-IS / TO-BE**;
- BPMN-модели производственного процесса;
- структурированный анализ проблем и точек боли;
- концепция аналитического решения;
- перечень ключевых показателей;
- процесс анализа и формализации требований;
- анализ рисков, ограничений и допущений.

В результате заказчик получает структурированное представление о текущем состоянии производственного процесса и набор требований, необходимый для дальнейшего проектирования и реализации аналитической системы мониторинга.
